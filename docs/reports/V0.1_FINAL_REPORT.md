# V0.1_FINAL_REPORT.md — Character Identity Board（影视人物统一与镜头人物管理系统）

> 日期：2026-08-17 · 硬件：RTX A6000 48GB / CUDA 13.2 / Python 3.12

---

## A. Result / 结论

**PARTIAL（系统可运行且核心流程通过，但真实BBC片段暴露出Reference Mode跨人物过度归类；不能把自动身份结果视为PASS）**

总体：一套**真实可运行、已端到端验证**的本地 Web 系统已完成。上传影片 → 自动分镜 → 提取镜头内人物 → 建立 Tracklet → 嵌入 → 聚类为 A/B/C/Unknown → 六视图 UI → 人工纠错（改名/合并/拆分/重指派/Unknown）→ 导出（JSON/CSV/Contact Sheet/HTML）均可真实工作。
合成双特写 fixture 上 Discovery Purity 达到 1.00，但真实 BBC 体育直播片段上原始 Reference Mode 自动准确率仅 **0.25（1/4）**，并出现不同人物 cosine=1.0 的过度归类。新增门控后，4/4 全部进入 Review Queue，错误自动确认数为 **0/4**。因此 V0.1 的身份自动化能力必须标记 **PARTIAL**；人工 Review Queue 是当前安全交付路径。
