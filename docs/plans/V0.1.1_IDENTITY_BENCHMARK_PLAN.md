# Character Identity Board V0.1.1 Implementation Plan

> **For Hermes:** Execute this plan task-by-task with strict TDD and fresh verification.

**Goal:** Build a reproducible open-set identity benchmark and safe automatic re-evaluation path without entering V0.2, Face Swap, redraw, or ComfyUI.

**Architecture:** Keep existing YuNet+SFace embeddings and manual-review safety boundary. Add an offline benchmark layer with immutable ground-truth/query manifests, strategy/calibration metrics, and a separate re-evaluation service that never mutates manual assignments. Add only the API/UI fields needed to inspect gate evidence.

**Tech Stack:** FastAPI, SQLAlchemy/SQLite, OpenCV YuNet+SFace, NumPy, pytest, JSON evidence artifacts.

### Task 4: Implement safe re-evaluation

**Files:**
- Create: `backend/app/identity_reevaluation.py`
- Modify: `backend/app/api/exports.py` or create `backend/app/api/identity.py`
- Modify: `backend/app/models.py` only if a versioned result record is required
- Test: `tests/test_v011_reevaluation.py`

Implement `re_evaluate_automatic_assignments(project_id, strategy, threshold, unknown_threshold, dry_run)`. Select only automatic/reference assignments; skip every manual assignment; preserve old values in `ReviewAction` history; produce an old-vs-new comparison. Dry-run performs no DB writes. Non-clear results remain `pending`/`UNKNOWN`; never auto-confirm a negative conflict.

Expose `POST /projects/{id}/identity/re-evaluate` with the requested parameters and return counts plus row-level comparison. Add an integration test proving manual assignments are byte-for-byte unchanged.
